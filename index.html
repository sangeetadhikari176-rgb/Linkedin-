Use the same list on every device

By default this list is saved inside this browser only. Connect a free Firebase (Firestore) database and the list lives online instead, so your phone, laptop and any other device all show the same data.

  1. Create a free project at console.firebase.google.com
  2. Open Build › Firestore Database › Create database › start in test mode.
  3. In the Rules tab, paste the rules below and press Publish.
  4. Open Project settings › Your apps › Web (</>) and register a web app.
  5. Copy the firebaseConfig object it shows you and paste it in the box below.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /tracker/data { allow read, write: if true; }
  }
}

These rules let anyone who has your config edit the data, which is fine for a personal list — just keep sensitive information out of it.

Pasting it here connects this device only, and it stays saved even after you upload a new version of the file. To connect every device automatically, paste the same config into the FIREBASE_CONFIG line near the top of this file's script instead.
