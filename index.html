Use the same list on every device

A Firebase (Firestore) database is already built into this page, so the list lives online rather than in one browser. Your phone, laptop and any other device that opens this page show the same data, and changes appear on the others within a second. There is nothing to set up.

The only thing kept outside this file is the database's rules. In the Firebase console open Firestore Database › Rules and make sure these are published, otherwise the page can load but not save:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /tracker/data { allow read, write: if true; }
  }
}

These rules let anyone who has the config inside this file edit the data, which is fine for a personal list — just keep sensitive information out of it.

Only if you ever want this one device to use a different Firebase project: paste that project's firebaseConfig below and press Connect. It is saved in this browser alone and overrides the built-in project until you press “Use the built-in project”.
